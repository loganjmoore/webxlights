# apps/web

The Vue 3 + TypeScript single-page app: layout editor, sequencer, visualiser, shader library.
The marketing site is the static HTML under `public/site/`. See the
[root README](../../README.md) for setup.

```bash
npm run dev        # from the repo root; proxies /api and /sanctum to localhost:8000
npm run test -w apps/web
```
