About

A small open source project by people who put pixels on their houses.

pixl is built by hobbyists who sequence their own shows in xLights and wanted the same thing in a browser: for the laptop with nothing installed, for the friend who helps with the show, for the files that should save themselves. It is not a company and there is nothing to buy. The hosted copy is free to use within the monthly limits on the two features that cost money to run.

What we care about

  • Honesty about what it does. The features page lists what exists. When an import cannot map something, it says so. When a lyric timing is roughly right, it says roughly.
  • Feeling like a tool. Dark, dense, keyboard-friendly, panels that behave like windows. Something a long-time xLights user can trust on sight.
  • Staying open. GPL-3.0, like xLights. Read it, run it, change it. Self-hosting.
  • Not fighting xLights. It is the better tool for a lot of shows, and we say so. Why we still love it.

Get in touch

Bugs, ideas and questions go to GitHub issues. Security problems go to the address in SECURITY.md, not to a public issue.
