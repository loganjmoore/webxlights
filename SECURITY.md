# Security

## Supported versions

Security fixes are applied to the latest code on `main`. If you self-host webXLights, keep
your installation up to date; older revisions are not maintained separately.

## Reporting a vulnerability

Email **loganjmoore@gmail.com** with "webXLights security" in the subject. Say what you found,
how to reproduce it, and what you think it lets an attacker do. You will get a reply within a few
days. Please do not open a public issue for a vulnerability until a fix has shipped.

## Other issues

For bugs, feature requests and general questions, use
[GitHub Issues](https://github.com/loganjmoore/webxlights/issues).

For setup guidance, see the [self-hosting checklist](README.md#self-hosting-checklist).
